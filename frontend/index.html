How to Use

Status

⚪ Todo No PR yet
🟡 In Progress PR is a draft
🔵 In Review PR is ready for review
✅ Done PR has been merged
🟥 Error PR closed without merge

Task IDs

Format: T{sprint}.{seq}, e.g. T1.1, T2.3. PRs with [T1.1] in the title are auto-linked.

Aggregated PRs

A single PR can cover multiple tasks. Title format: [T1.1][T1.2] description.

Data Refresh

CI rebuilds every 5 minutes, aggregating PR statuses across all repos.
